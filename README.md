# Anteproyecto v2 · Mecánica automotriz a domicilio

Sitio estático de **solo lectura**. Es el documento de trabajo navegable para la reunión de socios del domingo 15 de noviembre de 2026. No es una página comercial ni un acuerdo societario.

## Cómo abrirlo

Abre `index.html` con doble clic en cualquier navegador (también en el celular). No necesita servidor, conexión a internet ni instalación.

## Reglas del sitio

- HTML y CSS, con un script mínimo solo para el menú.
- Sin formularios, cookies, analítica, fuentes externas ni recursos de terceros.
- No pide ni guarda datos personales. Los identificadores (CLI-0001, VEH-0001, OT-0001) son ficticios.
- Todo el contenido sale de `docs/anteproyecto-v2.md`. Si cambia el documento, hay que actualizar las páginas.
